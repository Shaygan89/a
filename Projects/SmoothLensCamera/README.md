# Smooth Lens Camera

A minimal Camera2 + Jetpack Compose camera app source project for Android 11+. It opens the rear camera, shows the live preview, offers only zoom stops reported as supportable by the selected camera configuration, and records MP4 video to `Movies/SmoothLensCamera` using MediaStore. This archive was not compiled in the current environment.

## Version configuration

- Gradle distribution: 8.13
- Android Gradle Plugin: 8.12.0
- Kotlin: 2.0.21
- Compose compiler Gradle plugin: 2.0.21 (matches Kotlin)
- Compose BOM: 2024.09.00
- compileSdk / targetSdk: 36
- minSdk: 30
- Java/Kotlin bytecode target: 11

**Gradle runtime JDK:** use JDK 17 in Android Studio. AGP 8.12 requires Gradle 8.13 and JDK 17; JVM 11 is used as the generated bytecode target, not the Gradle runtime. The request listed AGP 8.12.0 in its mandatory version list but later also requested 8.13.2. This project uses 8.12.0 to follow the main version list. One compatibility caveat: Kotlin’s published table lists Kotlin 2.0.21 as fully supported only through Gradle 8.8 and AGP 8.5; using it with the explicitly requested Gradle 8.13 / AGP 8.12 falls outside that fully tested matrix and may produce compatibility warnings. The Kotlin pin is retained rather than silently changing a requested core version.

## Build limitation in the supplied archive

`gradle/wrapper/gradle-wrapper.properties` and launch scripts are included, but **the official `gradle-wrapper.jar` could not be bundled in this environment**: no Gradle installation or wrapper JAR was present, and external downloads were unavailable. As a result, `gradlew.bat assembleDebug` cannot run from this ZIP until the official wrapper JAR is restored. Open the project in Android Studio and use its Gradle/JDK setup, or from a machine with Gradle installed run `gradle wrapper --gradle-version 8.13` to generate the wrapper files. No successful `assembleDebug` is claimed.

## Open in Android Studio

1. Extract the ZIP and open the `SmoothLensCamera` directory as a project.
2. Set **Gradle JDK** to JDK 17 and ensure Android SDK Platform 36 is installed.
3. Restore/generate the Gradle wrapper JAR as described above, then sync Gradle.
4. Build with `gradlew.bat assembleDebug` and install `app/build/outputs/apk/debug/app-debug.apk` on the device.
5. Grant camera permission. The first record tap requests microphone permission; if microphone permission is denied, recording proceeds without audio.

## Zoom handoff notes

Zoom transitions update `CaptureRequest.CONTROL_ZOOM_RATIO` (or `SCALER_CROP_REGION` when ratio control is unavailable) on the same repeating Camera2 session. During recording, that session continues to target the preview surface and MediaRecorder surface; the transition is therefore applied to captured frames rather than a preview-only visual effect. The app reads logical-camera capabilities, physical IDs, focal lengths, zoom limits, and the active physical camera ID when reported.

Camera2 does not provide a general API to force the HAL to switch to a specific physical sensor at an exact ratio. Whether the Galaxy A56 performs a physical handoff, and how that handoff looks in the recorded MP4, must be tested on that device. No device-level result is claimed by this source package.
